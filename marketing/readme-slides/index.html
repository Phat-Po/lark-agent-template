Lark Agent Template

A ready-to-use Feishu/Lark AI agent with tool calling,
observability harness, and extensible plugin system.

Python 3.11+ MIT License Docker Ready 8 Built-in Tools

The Problem

  • Hand-write lark-oapi integration from scratch
  • Build conversation memory and session management
  • Add metrics, tracing, idempotency per tool
  • Handle error envelopes and retry logic
  • Configure Docker and deployment scripts
VS
  • Clone, configure, run in 5 minutes
  • Auto-harness wraps every tool
  • Built-in observability stack
  • Provider-agnostic LLM
  • Docker Compose one command

What You Get

🛠️ Tool Calling Agent
LLM decides when to call tools. Results feed back for multi-step reasoning. Up to 10 rounds per message.
📊 Observability Harness
Metrics, tracing, idempotency, schema validation — automatically applied to every registered tool.
🧠 Dual Memory System
Session history for conversation context + persistent SQLite memory per user for long-term facts.
🔌 One-Decorator Extension
Add a new tool with @register_tool. Drop the file in src/tools/. Restart. Full harness coverage, zero config.

5 Minutes to Live

$ git clone https://github.com/Phat-Po/lark-agent-template.git
$ cd lark-agent-template
$ cp .env.example .env # fill in LARK_APP_ID, LLM_API_KEY
$ docker compose up --build
 
✓ lark_channel_started
✓ agent_ready tools=8 model=gpt-4o
